                    ⚡ 立即使用方案
═══════════════════════════════════════════════════════════════

【方案一】手动创建快捷指令 (推荐，5 分钟完成)

1. 打开 iPhone 上的「快捷指令」App
2. 点击「+」创建新快捷指令
3. 添加操作 → 搜索「URL」
4. 输入以下任一 URL：
   - troll-openjb://cmd_toggle_wifi      (WiFi 开关)
   - troll-openjb://cmd_toggle_bluetooth (蓝牙开关)
   - troll-openjb://cmd_toggle_flashlight (手电筒)
   - troj://wifi  (短 URL，同上)
5. 添加操作 → 搜索「打开 URL」
6. 命名快捷指令，点击「完成」

【方案二】使用 Siri

1. 先按方案一创建一个快捷指令
2. 对 Siri 说「嘿 Siri，[快捷指令名称]」
3. Siri 会自动执行

【方案三】添加到主屏幕/Widget

1. 长按已创建的快捷指令
2. 分享 → 添加到主屏幕
3. 或添加快捷指令 Widget 到主屏幕

                    🔧 技术报告
═══════════════════════════════════════════════════════════════

编译失败原因分析:

1. WSL2 文件系统不稳定
   - /usr/lib/llvm-14/bin/clang 等文件间歇性"无法访问"
   - 重启 WSL 后暂时恢复，但很快又失效
   - 可能原因：Windows 与 WSL 文件系统同步问题

2. 网络超时严重
   - GitHub 下载持续超时 (exit 124/28)
   - 所有镜像源 (xybp888, DerekSelander, Gitee) 均失败
   - 无法下载 Theos toolchain 和 iOS SDK

3. Theos 编译链不完整
   - clang 实际是 bash 包装器脚本，非真正的交叉编译器
   - 缺少 stdarg.h, stdbool.h 等标准头文件
   - 无法正确交叉编译 ARM64 代码

已尝试的解决方案:
✗ apt install clang lld (包不完整)
✗ git clone theos (makefiles 目录为空)
✗ 下载预编译 toolchain (网络超时)
✗ 创建符号链接绕过 (Exec format error)
✗ env -i 清洁环境变量 (仍失败)
✗ 后台编译进程 (exit code 127)
